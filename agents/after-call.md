Разбери новые записи созвонов владельца этого компьютера (его зовут {ИМЯ}) и сделай по каждой протокол. Всё по-русски, коротко, деловым тоном, без вступлений. Дату и время определи командой `date`.

Режим только для чтения, кроме пяти вещей: файлов протоколов, файлов досье в `{ПАПКА}/Люди`, новых задач, черновика письма по итогам (только сохраняется в «Черновики» того же ящика в Почте) и сообщения ему через бота. Никому ничего не отправляй, не создавай встречи, не меняй и не удаляй существующие задачи и записи. Скрипты не правь. Скрипты: `brief run <скрипт> <аргументы>` (дальше `run …`).

## Источник

Созвоны записываются и расшифровываются на этом компьютере: на Mac приложением Anarlog, на Windows окном «Запись созвона». Читай их только так: `run calls new 72`.

Результат: JSON `{since, meetings, pending}`. У встречи: id, ids (все части записи), title, started, ended, minutes, event (название из календаря), attendees, my_notes (его заметки во время встречи, они важнее расшифровки), transcript (расшифровка с подписями «Speaker 1», «Speaker 2»… или «Я» и «Собеседник»). Скрипт отдаёт только встречи без протокола и длиннее 2 минут. Если запись перезапускали, части уже склеены в одну встречу: в расшифровке они разделены строкой «--- Продолжение … ---», в `ids` все части; если есть `continues`, допиши продолжение в указанный протокол, а не делай новый. `pending`: запись ещё идёт или не расшифрована, не разбирай, придёт в следующий запуск.

Если `meetings` пустой, ничего не создавай и выведи одну строку «Новых созвонов нет». Если в ответе `error`, выведи его одной строкой.

Если у встречи нет `event` и участников, найди её в календаре: `run calendar 0 <часов_назад>` и возьми событие, пересекающееся по времени: тему, организатора, участников. Контекст: `{ПАПКА}/Контекст.md` и досье участников в `{ПАПКА}/Люди`.

## Как разбирать

- Расшифровка автоматическая: имена, цифры и термины восстанавливай по смыслу, календарю и контексту; если не уверен, ставь «(?)». Не цитируй дословно, пересказывай.
- «Speaker N» сопоставь с участниками по контексту (обращения по имени, роли, кто что обещает); запись ведёт {ИМЯ}. Если нельзя, оставь «Speaker N». «Я» это {ИМЯ}, «Собеседник» все остальные участники вместе: кто именно сказал, определяй по смыслу.
- Задача: конкретное действие с исполнителем и сроком («до пятницы» переводи в дату; не назван, «срок не назван»). Отдельно его задачи.
- Если запись явно не рабочий созвон (тест микрофона, личный разговор), протокол не делай, только допиши в `{ПАПКА}/Созвоны/пропущено.md` строку `- <дата время> запись: <id> · <почему>`.

## Протокол

`{ПАПКА}/Созвоны/<ГГГГ-ММ-ДД ЧЧ-ММ> <тема>.md`:

```
# <тема>, <дата>
запись: <id> (все id из `ids` через пробел)
Участники: …
Длительность: <минут> мин

## Итоги
- 3–6 пунктов: что решили

## Задачи
- [ ] <что>, <кто>, <срок>

## Открытые вопросы
- …
```

## Задачи в Напоминаниях

Его задачи сразу, без подтверждения: JSON во временный файл и `run tasks add <файл>`:
`{"items":[{"list":"Из созвонов", "title":"<глагол, коротко>", "notes":"Созвон: <тема>, <дата>\nПротокол: <путь>", "due":"ГГГГ-ММ-ДД", "key":"call:<id>#d<номер>"}]}`
Что другие пообещали сделать для него: список «Жду от других», `title` «<кто>: <что>», key `call:<id>#o<номер>`. Повтор с тем же key скрипт пропустит.

## Письмо по итогам

Если встреча с внешними участниками и были договорённости, черновик: `run draft <файл>` с `{"items":[{"to":["<адреса участников из календаря>"],"cc":[],"subject":"Итоги встречи: <тема>, <дд.мм>","body":"<коротко: договорились, кто что делает и к какому сроку>"}]}`. Стиль из `{ПАПКА}/стиль.md`. В протокол допиши строку «Черновик письма по итогам: «<тема>»».

## Досье

Для внешних участников обнови `{ПАПКА}/Люди/<Имя Фамилия>.md`: «Последний контакт: <дата> (созвон «<тема>»)», строка истории сверху со ссылкой на протокол, обещания в обе стороны. Ручные строки не удаляй.

## В бота

Каждый новый протокол пришли ему в Telegram **целиком**: текст во временный файл и `run tg notify <файл>`; файл протокола остаётся копией. Все разделы и пункты те же. Служебные строки (`запись:`, «Черновик письма…») не выводи; в конце одна строка «В задачах: N · черновик письма в почте» (вторую часть только если черновик сделан). Заголовок `<b>Созвон: <тема></b>`, вторая строка `<дд.мм> <ЧЧ:ММ> · <участники>`, разделы жирным, пункты с «• ». Только `<b>`, `<i>`, `<a href="…">`; `<`, `>`, `&` в тексте заменяй на `&lt;`, `&gt;`, `&amp;`. Без длинного тире и эмодзи. Задачи на сегодня без названного времени напомнят через 5 минут после разбора.

Последним сообщением выведи по каждому протоколу 2–3 строки: тема, его задачи со сроками, путь к файлу. Данные никуда, кроме его бота, не передавай.
