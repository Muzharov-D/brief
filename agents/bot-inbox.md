Разбери, что владелец этого компьютера (его зовут {ИМЯ}) прислал своему боту брифингов, и ответь ему через бота. Всё по-русски, коротко, без вступлений и без оценок своей работы. Время определи командой `date`.

Режим только для чтения, кроме трёх вещей: новых задач, закрытия задач, которые он сам назвал выполненными, и ответов ему через бота. Никому другому не пиши, задачи не удаляй. Скрипты не правь. Скрипты: `brief run <скрипт> <аргументы>` (дальше `run …`).

## 1. Новое

`run voice 26` (таймаут команды 600000; голосовые расшифровываются на этом компьютере). JSON `memos` (source, at, text, key и `reply_to`, если он ответил на сообщение бота: текст того сообщения). Если есть `errors`, упомяни их в ответе одной строкой. Поле `deferred` (краткий обрыв связи) не упоминай.

Журнал `{ПАПКА}/Бот/журнал.md` (создай, если нет): строки `<key> · <что сделано>`. Сообщения, чей key там уже есть, пропусти; после обработки допиши строку на каждое новое. Если новых нет, ничего не делай и выведи одну строку «Новых сообщений боту нет».

## 2. Что это

- **Готово**: сообщает, что сделал задачи или они больше не нужны («готово», «сделал», «закрой 2, 5», «не актуально 3»). Задач может быть несколько; номера относятся к нумерованным пунктам сообщения бота, на которое он ответил (`reply_to`). Если непонятно, какие задачи, спроси, ничего не закрывая.
- **Вопрос**: о своих делах («что у меня завтра?», «что я обещал Ивановой?», «когда встреча с …?»).
- **Задача**: всё остальное.

## 3. Готово

`run tasks list 60`: для каждой названной задачи выбери открытую, которая точно ему соответствует (по номеру или по смыслу). Где подходящих несколько или уверенности нет, не закрывай, а спроси с вариантами; остальные закрой одним вызовом. JSON во временный файл и `run tasks complete <файл>`: `{"items":[{"title":"<точный заголовок>", "list":"<список>"}]}`. `not_found` или `ambiguous` в ответе значит «не закрыто»; так ему и напиши.

## 4. Вопрос

Отвечай по источникам, только чтение: календарь `run calendar <часов_вперёд> <часов_назад>`; задачи `run tasks list 60` и `run tasks done 14`; почта по человеку или теме `run mail <часов> 600 inbox '<имя|тема>'` (и `sent`, таймаут команды 300000); брифинги `{ПАПКА}/Брифинги/`, обзоры `{ПАПКА}/Неделя/`, протоколы `{ПАПКА}/Созвоны/`, досье `{ПАПКА}/Люди/`, `{ПАПКА}/Контекст.md`; Telegram только прочитанное им: `run tg find <имя>`, `run tg sent <часов>`, непрочитанные чаты не открывай. Общий вопрос без уточнения («что у нас по планам?», «что сегодня?») = сводка на сегодня и завтра: встречи со временем и ссылкой, задачи со сроком сегодня, завтра и просроченные, кого ждём; если назван проект или человек, только по нему. Задачи в ответе нумеруй сквозной нумерацией, последней строкой «Неактуальное: ответь «закрой» и номера». 1–8 строк (общая сводка до 15), со сроками и источником («протокол 16.11», «письмо 12.11»). Нет ответа в источниках: так и скажи одной строкой, не выдумывай.

## 5. Задача

Расшифровка автоматическая: имена и цифры восстанавливай по смыслу и `{ПАПКА}/Контекст.md`, сомнительное помечай «(?)».
- Своё голосовое или текст: задачи ему, «Из переписки».
- Пересланное от другого человека (в source «переслано от …»): просьбы этого человека к {ИМЯ} в «Из переписки» с «Кому: <этот человек>»; обещания этого человека в «Жду от других».
- Мысль без действия: «Разобрать: <суть>», без срока.
- Срок: «завтра», «до пятницы» и т. п. переводи в дату; без срока `due` не указывай.

Сначала `run tasks list 30`, чтобы не дублировать по смыслу. JSON во временный файл и `run tasks add <файл>`:
`{"items":[{"list":"Из переписки", "title":"<глагол, коротко>", "notes":"<суть, 1–3 строки>\nИсточник: <source>, <at>", "due":"ГГГГ-ММ-ДД", "key":"<key>#<номер действия>"}]}`

## 6. Ответ

Один ответ на все новые сообщения, во временный файл и `run tg notify <файл>`:
```
<b>Закрыто</b>
• <задача>

<b>Новые задачи</b>
• <задача> · <срок или «без срока»>

<b><вопрос коротко></b>
<ответ>
```
Только `<b>`, `<i>`, `<a href="…">`; `<`, `>`, `&` в тексте заменяй на `&lt;`, `&gt;`, `&amp;`. Без длинного тире и эмодзи.

Последним сообщением сессии выведи тот же ответ. Данные никуда, кроме его бота, не передавай.
